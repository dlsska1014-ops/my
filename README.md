# 똑똑한 가계부 V22.8.58 챌린지·최근 기록 UI/UX

V22.8.57의 홈 우측 기록과 챌린지 계산을 유지하면서, 날짜별 진행 상태와 기록 아이콘의 사용성을 개선한 누적 패키지입니다.

## 이번 단계

- 7일 이하 챌린지는 요일·날짜 칸으로 `무지출 성공·지출 있음·오늘 진행 중·예정` 구분
- 8일 이상 챌린지는 과밀한 날짜 칸 대신 달성률 퍼센트·완료 일수로 자동 전환
- 홈 본문과 펼친 데스크톱 사이드바에서 같은 상태 계산과 진행 정보를 사용
- 우측 기록의 추상 문자 아이콘을 수입·식비·카페·교통·의료·쇼핑·주거·구독·교육·여가 SVG로 교체
- 날짜별 건수·지출 합계, 실제 분류 배지, 결제수단·사용자 정보를 명확한 위계로 표시
- 키보드 포커스와 색상 외 상태 모양·접근성 이름 보강
- 홈 초기 HTML은 기준 픽스처 35KB, 실사용 200행·피드 10장 조건 44KB 이하 예산을 적용
- immutable 셸·V5 번들을 `v22858` 주소로 갱신
- 총 1,349개 자동검사 통과
- 신규 SQL·Supabase 스키마·환경변수·Secret·Kakao Developers·OpenBuilder 변경 없음

## 운영 적용

1. 현재 Cloudflare Worker 전체 소스를 백업합니다.
2. 패키지의 `src/index.js` 전체로 교체합니다.
3. 저장·배포 후 `10_VERIFY_AFTER_DEPLOY_V22_8_58.ps1`을 실행합니다.
4. 로그인 홈을 새로고침하고 1440px·390px에서 챌린지와 우측 기록을 확인합니다.

운영 Supabase의 V22.8.46 참여자 역할 SQL은 이미 적용된 상태를 전제로 하며 기존 SQL을 다시 실행하지 않습니다. `/app` 대량 월 요청 수와 `/skill` 호출자 인증은 `KNOWN-ISSUES.md`에서 별도 운영 과제로 관리합니다.
