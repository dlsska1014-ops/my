# 똑똑한 가계부 V22.8.61 모바일 화면 보정

V22.8.60 기능·UI 신뢰성을 유지하면서 실기기에서 보고된 모바일 상단바, 전체 메뉴, 하단 입력, 빠른 입력, 날짜 입력의 화면 결함을 보정한 누적 패키지입니다.

## 이번 단계

- 정의되지 않은 CSS 토큰(`--action`, `--accent-soft`, `--soft`) 별칭 추가로 하단 `입력` 탭 아이콘 복구
- 모바일 공통 `작업` 버튼을 상단바 안으로 옮겨 `전체 메뉴`와의 겹침·문구 잘림 제거
- 전체 메뉴 서랍에서 홈과 중복되는 달력·예산 위젯을 접고 항목 터치 영역을 48px로 확대
- 빠른 입력 시트의 실제 스크롤 잠금과 중첩 스크롤 제거로 배경이 대신 움직이던 현상 해소
- 빠른 입력 내용·결제수단 칩에 분류 기반 아이콘 추가(홈 HTML 예산을 위해 CSS로 렌더)
- 챌린지 `시작일`·`목표일` 등 날짜 입력이 카드를 밀어내던 그리드 계산 수정
- immutable 셸·내비게이션·V5 번들을 `v22861` 주소로 갱신
- 총 1,501개 자동검사 통과

## 이전 단계(V22.8.60)

- 챌린지 설정을 화면 안에서 저장해 주소·스크롤 위치를 유지
- `7일 → 8일` 변경 직후 본문·사이드바를 퍼센트형으로 함께 갱신
- 저장 오류·세션 만료·권한 부족·입력 오류를 화면 안에서 구분
- 비 JavaScript 브라우저의 기존 303 제출 호환 유지
- 연간·목표·예산 알림 관련 경로의 현재 메뉴 표시 보정
- 모바일 거래 수정·키워드 삭제·챌린지 저장 조작 영역 확대
- 공개 홈·`ads.txt` HEAD 점검과 카카오 `/skill` 256KiB 본문 상한

- 신규 계정 생성 오류를 중복 이름·RPC 미적용·스키마 캐시·권한·일시 장애로 구분
- 계정 생성 후 초대 참여나 자동 로그인 실패가 발생해도 이미 생성된 계정을 다시 만들도록 안내하지 않음
- 세션 버전 조회 장애 시 버전 1로 통과시키지 않고 로그인 세션을 안전하게 거부
- 우측 최근 기록은 월 전체를 읽지 않고 DB에서 최대 81건만 조회하며 현재 필터 합계를 표시
- 최근 기록이 80건을 넘으면 표시 한도를 알리고 전체 보기로 연결
- 12개월 분석 9,000건 초과 시 일부 분석임을 명시하고 중복 연간 조회 제거
- 홈 초기 HTML은 기준 픽스처 35KB, 실사용 200행·피드 10장 조건 44KB 이하 예산을 적용
- immutable 셸·내비게이션·V5 번들을 `v22860` 주소로 갱신
- GitHub PR·main 푸시마다 전체 검증을 실행하는 Actions 워크플로 추가
- 신규 SQL·Supabase 스키마·환경변수·Secret·Kakao Developers·OpenBuilder 변경 없음

## 운영 적용

1. 현재 Cloudflare Worker 전체 소스를 백업합니다.
2. 패키지의 `src/index.js` 전체로 교체합니다.
3. 저장·배포 후 `10_VERIFY_AFTER_DEPLOY_V22_8_60.ps1`을 실행합니다.
4. 챌린지 `7일 → 8일` 저장, 신규 계정 생성·로그인과 1320px 이상 우측 기록을 확인합니다.

운영 Supabase의 V22.8.46 참여자 역할 SQL은 이미 적용된 상태를 전제로 하며 기존 SQL을 다시 실행하지 않습니다. `/app` 대량 월 요청 수와 `/skill` 호출자 인증은 `KNOWN-ISSUES.md`에서 별도 운영 과제로 관리합니다.
