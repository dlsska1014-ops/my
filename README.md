# 똑똑한 가계부 V22.8.54 조회 페이지 크기 조정

V22.8.53을 기준으로, 4라운드 성능 점검에서 확인된 DB 왕복 횟수를 줄인 패키지입니다.

## 이번 단계

- `fetchPostgrestRows` 기본 페이지 크기를 500 → 1000으로 조정
- 8,000건 월의 `/app` DB 호출 25회 → 18회, 거래 질의 16회 → 10회
- 페이지 크기를 PostgREST `max-rows`보다 크게 잡으면 결과가 조용히 잘리므로
  기존 클램프 상한 1000을 넘기지 않는 범위로 제한
- 회귀 검사 4개 추가 — 페이지 크기·질의 횟수·합계 대조(데이터 손실 없음)
- 4라운드 점검 결과 `PERF_A11Y_AUDIT_REPORT_V22_8_53.md` 추가
- 총 1,147개 자동검사 통과
- 신규 SQL·Supabase 스키마·환경변수·Secret·Kakao Developers·OpenBuilder 변경 없음

## 별도 과제로 남긴 항목

- **홈 HTML 예산** — 실사용 데이터에서 약 45KiB로 35KB 예산 초과. 피드 카드 축소·
  기본 건수 조정·예산 개정 중 방향 판단이 필요합니다.
- **`/app` DB 호출 예산** — 18회로 줄었지만 9회 예산은 여전히 초과. 집계 질의 또는
  RPC 도입이 정공법이며 실행 계획을 포함한 설계가 필요합니다.
- **`/skill` 호출자 인증** — `botUserKey`는 만료·회수 수단이 없는 자격증명입니다.
  Kakao OpenBuilder의 커스텀 헤더 지원 여부 확인이 선행되어야 합니다.

운영 Supabase의 V22.8.46 참여자 역할 SQL은 이미 적용된 상태를 전제로 합니다.
