# 똑똑한 가계부 V22.8.71 수정·삭제·복구 명령 결함 수정

V22.8.70 금액 파싱 수정을 유지하면서 기록을 고치고 지우고 되살리는 명령의 결함을 고친 누적 패키지입니다.

## 이번 단계

- `수정 NN번 날짜 어제`의 `어제`가 바꿀 값이자 대상 날짜로 읽혀 **다른 날의 NN번**을 건드리고 "변경했어요"라고 답하던 결함 수정
- 되돌리기 버퍼가 한 칸이라 연속 삭제 시 첫 기록이 안내와 달리 **복구되지 않던 기록 소실** 수정 (최근 10건 보관)
- `점심 6만원`은 받으면서 `수정 01번 금액 6만원`은 거절하던 비대칭 수정 — 수정도 입력과 같은 추출기 사용
- 수정 세션에서 확인을 거절해도 빠져나갈 방법이 없어 갇히던 문제에 `취소` 안내 추가
- 명령을 보내고 **DB에 저장된 행을 직접 읽어** 대조, 신규 회귀는 결함을 하나씩 되돌려 실제로 잡히는지 확인
- 사용자 화면 HTML 바이트 변화 0, 자원 주소 변경 없음 (웹 탭 새로고침 불필요)
- 총 2,443개 자동검사 통과

> ⚠️ 과거에 날짜가 바뀌지 않은 기록과 복구하지 못한 삭제분은 이 배포로 되돌아오지 않습니다.
