# 똑똑한 가계부 V22.8.55 피드 카드 마크업 축소

V22.8.54를 기준으로, 홈 HTML 예산을 향해 거래 카드 마크업을 줄인 패키지입니다.

## 이번 단계

- 거래 카드의 삭제 폼을 수정 폼에 통합 (`formaction` + `formnovalidate`)
- 카드마다 중복됐던 숨은 입력 4개와 `<form>` 한 쌍 제거, 삭제 확인창 유지
- 화면 텍스트를 복제하던 `data-search` 속성 제거, 빠른 검색을 본문 텍스트 기준으로 변경
- 실사용 200행 기준 홈 HTML 45.3KiB → 42.5KiB
- 검증에 실사용 200행 측정과 44KiB 상한 래칫 추가 (6행 픽스처 사각지대 해소)
- 변경된 immutable 자산 주소 상향: `mobile-home-v22855.js`, `mobile-home-shell-v22855.js`
- 총 1,149개 자동검사 통과
- 신규 SQL·Supabase 스키마·환경변수·Secret·Kakao Developers·OpenBuilder 변경 없음

## 남은 결정

**35KB 목표 예산은 아직 미달입니다** (42.5KiB, 약 7.7KiB 초과). 남은 차이는 거래
카드마다 즉시 렌더되는 수정 폼(카드당 약 1.2KiB × 10장)입니다. 마크업 축소만으로는
목표에 닿지 않으며 다음 중 하나를 선택해야 합니다.

1. 수정 폼 지연 렌더 — 즉시 펼침이 페이지 재요청으로 바뀌는 UX 변화
2. `AGENTS.md` 예산을 실측 근거와 함께 개정

`/app` DB 호출 9회 예산과 `/skill` 호출자 인증도 별도 과제로 남아 있습니다.
자세한 내용은 `KNOWN-ISSUES.md`와 `PERF_A11Y_AUDIT_REPORT_V22_8_53.md`를 확인하세요.

운영 Supabase의 V22.8.46 참여자 역할 SQL은 이미 적용된 상태를 전제로 합니다.
