# 똑똑한 가계부 V22.8.52 스킬 IP 가드·CSV 안전·이름 검증

V22.8.51 입력 금액·런타임 정규식 수정을 기준으로, 보안 점검에서 확인된 항목을 고친 보안 릴리스입니다.

## 이번 단계

- 카카오 `/skill`에 IP 단위 상한 추가 (`SKILL_IP_GUARD_LIMIT`, 기본 3000/분)
- 호출자가 정하는 `botUserKey`를 회전해 사용자별 제한을 우회하던 경로 차단
- CSV 내보내기에서 `=`·`+`·`-`·`@`·탭·CR로 시작하는 셀을 무력화해 스프레드시트 수식 실행 차단
- 순수 숫자 셀은 그대로 유지해 금액 표시와 재가져오기 호환 보존
- 웹 가계부 이름 검증을 카카오 대화용 종류 선택지에서 분리
- `가족 생활비`·`생활비`·`모임`·`여행` 등 자연스러운 이름 생성 허용
- 봇 명령어·번호·링크·전화번호·초대코드 형태·금액만 있는 이름은 계속 거부
- 회귀 검사 12개 추가, 총 1,141개 자동검사 통과
- 신규 SQL·Supabase 스키마·Secret·Kakao Developers·OpenBuilder 변경 없음

## 남은 위험

`/skill`의 IP 상한은 완화책입니다. `botUserKey`는 여전히 만료·회수 수단이 없는
자격증명이므로, 근본 해결을 위해 Kakao OpenBuilder의 커스텀 헤더 지원 여부를 확인하고
공유 시크릿 검증을 추가해야 합니다. 자세한 내용은 `00_READ_FIRST_V22_8_52.md`와
`SECURITY_AND_FEATURE_AUDIT_V22_8_51.md`를 확인하세요.

운영 Supabase의 V22.8.46 참여자 역할 SQL은 이미 적용된 상태를 전제로 합니다.

먼저 `00_READ_FIRST_V22_8_52.md`를 확인하세요.
