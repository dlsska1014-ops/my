# V22.9.55 남은 확인

- 운영 Cloudflare 요금제·CPU 설정·실제 HTTP CPU/1102와 subrequest 계측은 미확인입니다. 공식 limits의 Free HTTP 10ms와 Node process CPU를 혼동하지 않습니다.
- 읽기 쉬운 CSV의 별도 원문·수식 방지 접두어를 완전 복원하는 모드는 구현하지 않았습니다. 무조건 접두어를 제거하지 않습니다.
- iOS Safari·Android Chrome·카카오톡 인앱·실제 OS 파일 선택/클립보드·VoiceOver/TalkBack·실제 BFCache·암호화 Excel은 별도입니다. 로컬 Chrome의 합성 workbook과 손상 workbook 검증을 실기기로 보고하지 않습니다.
- D 열 연결 UI는 별도 지시문입니다. 임의 매핑이 바뀌는 재분석은 원본/리비전/계열과 저장 중·불명확 상태를 서버에서 다시 검증해야 합니다. 기존 previous_import_token은 같은 원본·기준의 재분석만 지원합니다.
- V54의 실제 환급 정산 반영·운영 진단 자료·카카오/콘솔·별도 테스트 환경 등 남은 항목은 그대로입니다.

이 문서는 후속 계획이며 운영 작업은 실행하지 않았습니다.
