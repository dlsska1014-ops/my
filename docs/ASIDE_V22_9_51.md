# V22.9.51 실기기 미확인 항목

로컬 구현·자동 검증과 실기기·운영 적용을 구분합니다. 이번 작업에서는 운영을 변경하지 않았습니다. 아래 항목은 미확인입니다.

- iOS Safari·Android Chrome·카카오톡 인앱에서 실제 금액 키보드·한글 조합·중간 삽입·삭제·선택 범위·커서를 확인합니다.
- OS 클립보드로 ₩12,000·8,900원과 잘못된 쉼표를 붙여넣고 오류 원문 보존, 증액 차단, 직접 정정 후 저장을 확인합니다.
- 같은 탭에서 집 초안 → 여행 → 집, 로그아웃 → 다른 계정 → 원래 계정, 새로고침 → 일반 버튼·quick=1·hash 진입을 확인합니다. 다른 범위의 초안은 적용하거나 지우지 않아야 합니다.
- 응답이 불명확한 요청은 목록을 먼저 확인합니다. 내용을 바꾼 재시도는 기존 행을 바꾸거나 새 행을 만들지 않고 초안과 충돌 안내·기존 기록 수정 동선을 남겨야 합니다.
- VoiceOver·TalkBack에서 결과 칩·금액 오류·초안과 달력 날짜 충돌·삭제 대기와 되돌리기를 확인합니다.
- 삭제 대기 중 빠른 입력, 포인터·키보드 초점으로 일시 정지, 실제 이동과 뒤로 가기 캐시 복귀를 확인합니다.
- BFCache는 삭제 대기 중 다른 문서로 실제 이동한 뒤 뒤로 가기를 수행하고 pageshow.persisted와 브라우저의 미복원 사유를 함께 기록합니다. persisted=true인 경우 서버 상태를 다시 읽고 삭제 요청이 추가되지 않으며 타이머·되돌리기가 되살아나지 않아야 합니다. 로컬 Chrome은 no-store·관련 네트워크 자원·HTTPOnly 쿠키 변경 등의 사유로 cache-hit를 제공하지 않았습니다. 개인정보의 no-store를 제거하여 통과시키지 않습니다.
- 라이트·다크와 기존 네 톤, 금액 가리기·모션 줄이기에서 실제 터치·스크롤·초점·안전 영역을 확인합니다.

로컬 Chrome의 문자열 삽입은 실제 OS 클립보드를 검증한 결과가 아닙니다. 운영 카카오·관제·다크 알림 배지와 D·C 후속 항목도 별도입니다.
