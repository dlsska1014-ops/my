- Inherit bindings are now sent as `latest`.

- A missing `compatibility_flags` key is treated as an empty list.

## What the first real run settled

- The Versions API upload accepts only the literal `latest` as the `version_id` of an inherit binding, although the API reference says a version id is accepted.
- A version uploaded with inherit bindings returns resolved bindings when it is read back. They compared equal to the live version, including plain-text values.
- `GET /content/v2` returns `multipart/form-data` whose `index.js` part holds the exact deployed module bytes.
- The server etag is not the source SHA-256: `95e6d703…` for this version and `2c0d0768…` for V22.9.31. The script records the etag but does not require it to equal the source SHA-256.
- The version detail response includes `annotations`.
