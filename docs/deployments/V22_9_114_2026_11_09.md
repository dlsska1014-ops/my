## 사용자 질문(기록 없는 사람도 봇 호출·‘웹가계부’ 단추로 식별·구분할 수 있나) — 답(코드 변경 없음)
- 구분은 가능하다: 카카오는 스킬 요청에 botUserKey(봇별 사용자 고유값)·botGroupKey(방 고유값)·appUserId(앱 1489689 연결 뒤, 11-05 부터 도착 확인)를 주고, 링크 단추를 누를 때도 같은 값을 주소에 붙인다(V22.9.105 가 이미 읽음). 지금 코드는 ‘기존 채팅 계정 + 그 방 가계부 구성원’ 일 때만 들이므로(`auth/kakao-room-open.js`, 아니면 `no_user`·`not_member` → 로그인 화면), 한 번도 기록하지 않은 사람은 로그인 화면을 본다. 메뉴·도움말 호출만으로는 계정을 만들지 않는다(첫 기록이 계정·구성원을 만든다 — V22.9.43).
- 다음 판 후보(V22.9.115): 스킬 호출 때 그 방에 가계부가 이어져 있으면 (botGroupKey → 사용자 botUserKey) 명부 행을 올리고(이름 없음, 자리표시), 단추 주소의 두 값이 명부에 있으면 채팅 계정 + 구성원을 만들어 그 방 가계부 홈으로 들인다(선택: 카카오 멤버 API `GET /v2/bots/{botId}/group-chat-rooms/{botGroupKey}/members` 로 검증). 결정 필요: 자동 구성원 vs 소유자 승인, 가계부 없는 방의 소유자(첫 호출자?), 위조 키 위험(검증 없이 명부만 믿으면 안 됨).
