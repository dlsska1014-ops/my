# V22.9.49 적용 안내

Worker 소스 전체 교체가 필요한 로컬 준비본이며 이번 작업에서는 업로드·승격하지 않았습니다. SQL·환경변수·Secrets·카카오 콘솔 변경은 필요하지 않습니다. Git 게시와 운영 적용은 별도 범위입니다.

적용 후에는 실제 가계부에서 한 줄 입력 → 다섯 항목 확인 → 실제 입력칸 수정 → 재해석 → 저장값 확인을 수행합니다. 빠른 금액 더하기·지우기, 예산 초과 지출 저장과 형식 오류 차단, 날짜·취소 내역 초안 복귀를 확인합니다. iOS Safari·Android Chrome·카카오톡 인앱 키보드의 커서·통화 붙여넣기·IME와 VoiceOver·TalkBack의 초점·상태 안내는 실기기로 확인합니다. 라이트·다크·색상 테마·금액 가리기·모션 줄이기도 확인합니다.
