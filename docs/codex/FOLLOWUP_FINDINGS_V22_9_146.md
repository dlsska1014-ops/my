# V22.9.146 후속 발견 기록 — 실제 화면 사진·‘가상’ → ‘예시’·처리방침 이용 목적 추가 알림 (2026-11-25)

운영자(2026-11-25, 애드센스 결정 뒤 ‘애드센스 승인 목표를 우선으로 다음 단계를 진행하고 빠르게 검토·수정해 재검토’, 같은 날 ‘바로 진행’): 애드센스 마지막 신청 계획의 B4(실제 화면)·B5(처리방침의 집계 통계 공개 목적 알림)와 ‘가상’ 표현 정리를 재검토 전에 낸다.
공개 쪽·계산표·로그인 화면 옆 예시 카드의 글과 처리방침만 바뀐다 — SQL·Secret·쿠키·운영 변수 없음, 카카오 봇과 로그인 뒤 웹 가계부의 동작은 바뀌지 않는다.

## 바꾼 것
- 실제 화면 사진 네 장(홈·내역·방 내역·정산): 예시 시나리오의 카카오톡 문장(1:1 11문장·단톡방 9문장)을 QA 픽스처의 실제 봇 경로로 보내 만든 가계부를, 봇 답의 [웹 가계부 열기] 링크로 받은 세션으로 열어 머리 없는 Chrome 으로 찍었다(`tools/build-real-screens.mjs` — 생성 파일 `src/modules/assets/real-screens-images-v229146.js`, 주소 `/assets/real-screen-<이름>-v229146.webp`, 1년 캐시). 실제 이용자의 대화가 아니므로 화면 글도 ‘예시 문장을 봇과 같은 코드에 보내 만들었다’ 고 적는다.
- 싣는 곳: 첫 화면(미리보기 — PC 에서는 오른쪽 열·공동 가계부 묶음), /kakao-guide·/group-accountbook(사진 + 그 기록을 만든 예시 문장 목록), /demo(네 장 + 두 안내의 문장으로 가는 링크). 사진마다 보이는 숫자·글을 적은 대체 글과 찍은 방법·날.
- 공개 글·계산표·로그인 화면 옆 예시 카드의 ‘가상’ 을 ‘예시’(계산표 값과 단추는 ‘예제’)로 바꿨다. 낱말만 바뀐 글은 수정일을 올리지 않았다. 계산표 자산 주소 v229140 → v229146.
- 개인정보처리방침: 1절 처리 목적 목록에 2027-01-04 부터의 이용 목적(개인을 알아볼 수 없게 집계한 이용 통계의 공개) 한 줄, 2절에 그 내용, 12절에 이 개정의 성격을 더하고, 시행 전까지 머리 아래에 ‘개정 알림’ 상자를 둔다(공고일을 화면에 적지 않는다 — 12-04 안에 운영에 올리면 시행일 0시까지 만 30일이 넘는다).

## 발견

### S-1 공유 그림 대체 글의 ‘가상’ (P3, 남음)
- 공유 미리보기 그림(og:image)의 대체 글이 ‘…가상 데이터로 그린 웹 가계부 홈 화면 일부’ — 공개 화면의 남은 ‘가상’ 한 곳(meta 에만 있고 화면에는 보이지 않음).
- 그림 생성 도구(tools/build-og-images.mjs)가 그림과 함께 만드는 값이라 이 판에서는 두었다. 그림을 다시 만들 때 ‘예시 데이터’ 로 함께 고친다(새 검사가 지금 값을 알고 있어 고치면 그 줄도 바꾼다).

### S-2 이름 바꾸기 답의 조사 (P3, 남음)
- 카카오 ‘내 이름 서연’ 의 답이 ‘이 가계부에서 내 이름을 ‘서연’로 변경했어요’ — 받침 있는 이름에도 ‘로’ 를 붙인다(‘도윤’ 도 같음).
- 독립 검토가 찾은 이 판 전과 같은 카카오 답이다(이름 바꾸기 답). 이 판의 공개 문장 목록에 ‘@말해가계부 내 이름 서연’·‘내 이름 도윤’ 이 실려 독자가 그대로 보내 볼 수 있다. 카카오 판(12-03 이후)에서 이름의 받침에 따라 ‘으로/로’ 를 고른다.
