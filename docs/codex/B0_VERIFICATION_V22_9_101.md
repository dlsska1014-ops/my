## 수정 결과

최초 별칭 저장 실패나 예산 부족 뒤 복구되지 않던 P1을 수정했다. 기존 raw 또는 bot 별칭으로 선택한 사용자가 appUserId를 보내면 응답 뒤 links를 확인한다. 이미 같은 사용자에게 연결됐으면 확인 완료로 기억하며, 변경이 필요하면 기존 전역 식별 잠금 안에서 links·사용자·소유권을 새로 읽고 저장한다. 통합 계정은 기존 주 계정 해석과 충돌 보호를 유지한다.

연결 확인은 24시간, 충돌 결정은 10분 동안 기억한다. 캐시는 사용자 선택이나 인증에 쓰지 않는다. 꺼짐 충돌 캐시가 켜짐 뒤 제안을 막지 않도록 기능 상태를 구분한다. 읽기·쓰기·제안·해제 실패와 예산 생략은 완료로 기억하지 않으며 다음 app 포함 요청에서 재시도한다. 웹 로그인 자체가 꺼진 경우의 기존 V91 계약도 유지한다.

raw·bot 별칭이 없는 trusted 신규자만 B-7 app 주인 발견 조회를 수행한다. 기존 웹 주인 W를 발견한 경우에만 bot/app 별칭을 기록 전에 동기로 저장한다. 잠금 안에서 발견 주인이 바뀌거나 사라지면 저장과 거래를 중단한다. 검사에서 별칭 저장을 거절하면 raw·별칭·거래가 생성되지 않았고, 다음 요청은 처음부터 다시 계산했다. 주인 없는 새 raw는 응답 뒤에 처리한다.

독립 검토에서 발견 조회가 진행 중일 때 같은 bot의 app 없는 요청이 새 raw 계정을 만드는 경쟁을 재현했다. 식별 첫 조회부터 같은 isolate의 bot별 해석을 직렬화하고, 같은 요청의 seed 재확인은 재진입하도록 수정했다. 회귀 검사는 발견 조회 도중과 별칭 잠금 도중의 요청 겹침을 각각 확인한다. 꺼짐 제안 부재 검사의 잘못된 설정 키도 실제 `kakao_login_link_offers_v22991`로 고쳤다.
