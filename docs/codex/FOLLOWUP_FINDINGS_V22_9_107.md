## 고친 것 (V22.9.107)

- **D-1** (P2) 광고 자리·CSP·SDK 시작이 정본 주소 전체(`href`)와 같을 때만 됐다. 서버 게이트(`adsPublicRequestKeyV229106`)는 `url.search`·`url.hash` 가 있으면 빈 키를 돌려 광고 자리와 CSP 를 뺐고, 클라이언트(`adsActivationV229106`)는 `location.href` 를 비교했다. 외부 링크 유입 표시(`?utm_source=…`·`fbclid`·`gclid`)나 목차 앵커(`#section-n`)가 붙은 화면에는 광고가 없었다(Gemini P1 #1, 맞음. 심사에는 영향 없고 승인 뒤 수익에 영향). 고침: 서버는 https 정본 출처 + 정확한 경로, 클라이언트는 `origin + pathname`. 다른 호스트·다른 경로·http 는 그대로 제외. 프래그먼트는 서버에 오지 않는다.
- **D-2** (P3) 애드핏 FAQ 답(`ADFIT_POLICY_TEXT.faq`)이 ‘공개 가이드와 생활비 글처럼 로그인 없이 읽는 화면에’ 로 남아 방침·쿠키 문구(‘선정한 공개 생활비 글 6편의 본문 아래에’)와 달랐다(Gemini P2, 맞음). 고침.
- **D-3** (P3) 계산표 글 6편에서 ‘이 글에서 완성할 결과(결과 + 입력 안내 + 조건 표)’·예제 원본 표 1~2절·검산 절이 글의 원래 절 앞에 와 첫 화면이 길고 서사보다 원본 데이터가 먼저 나왔다(Gemini ③ 의 상단 과밀 지적과 겹침). 고침: 결과 한 문단 → 원래 절 → 조건 표(있는 글) → 예제 표 → ‘예제 검산과 계산표 열기’(입력 안내·검산 표·가상 예제 안내·링크 둘). 절 수는 같다(검사의 더한 절 = 결과 1 + 조건 1 + 묶음 수 + 검산 1).
- **D-4** (P3) 계산표에서 입력을 한 글자 고칠 때마다 결과 표가 통째로 사라졌다(`invalidate` 의 `output.replaceChildren()`, Gemini ②). 고침: 이전 결과를 ‘입력값을 바꾸기 전 결과입니다’ 띠와 함께 흐리게 남기고 CSV 저장만 막는다. 다시 계산하면 새 결과로 바뀐다. 계산표 자산 주소는 1년 캐시라 판을 올렸다(`/assets/living-worksheet-v229107-<slug>.html`; 옛 v229106 주소는 다음 판까지 같은 내용, 두 판 전은 404).
- **D-5** (P3) 계산표 입력 칸이 휴대폰 폭(390px)에서 1열이라 기본 예제만으로 4~5화면을 내려야 결과가 보였다(Gemini ②). 고침: 640px 이하 2열, 칸 글자 16px(iOS 자동 확대 방지), 표 칸 여백 축소.
- **D-6** (P3) 계산표 화면에 서비스 머리·꼬리가 없어 ‘돌아가기’ 링크 하나뿐이었다(Gemini ①). 고침: 머리 줄(말해가계부 › 생활비 가이드 글 › 설명 글)과 꼬리(설명 글·다른 글·방침·약관·문의). 내려받은 파일에서도 열리게 절대 주소를 쓴다. 공개 셸 전체(머리 메뉴·CSS)는 넣지 않았다(오프라인 파일·CSP `default-src 'none'` 유지).
- **D-7** (P3) 글 목록(/articles)에서 계산표가 있는 글을 구별할 수 없었다(Gemini ③ 의 배지 제안). 고침: 카드의 작성·수정일 줄에 ‘계산표 포함’(6편). 첫 화면 최근 글은 링크 목록이라 그대로다.
