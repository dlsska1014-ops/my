# V22.9.83 화면 점검과 1차 정리 (2026-10-28)

요청(사용자, 2026-10-28): 브라우저 홈의 좌측 메뉴, 통계·리포트류, ‘계획한다’ 안의 정기 수입·지출, 그 밖의 모든 탭에 UI·UX 문제가 많다.
‘계획한다’라는 이름도 이상하고 ‘본다·적는다’도 어설프다. 디자인 저장소 목록(Claude Code·Codex 디자인 스킬, 디자인·애니메이션·3D·제작 라이브러리)에서
쓸 만한 것을 살펴 달라. **운영 서버는 그대로 두고 별도 테스트 서버에서 확인한 뒤 적용한다.**

- 브랜치 `claude/v22983-uiux`(폴더 `my-v22983-uiux`), V22.9.82(PR #101) 위에 쌓음. 커밋·푸시·병합·배포는 하지 않았다.
- 전후 캡처: `review-artifacts/uiux-2026-10-28/` — `before/`(23화면 PC·모바일), `tall/`(전, PC 긴 화면), `after/`(후), `vp/`(후, 1280×800).

## 3. 테스트 서버

운영(`kakao-accountbook`, malhaebook.com)과 섞이지 않는다. 화면은 실제 앱 코드(`src/index.js`)가 그리고, 데이터는 QA 메모리 픽스처 위의 예시 데이터다.

- **내 PC(바로 쓸 수 있음)**: 폴더 `my-v22983-uiux` 에서 `npm run preview:app` → http://127.0.0.1:4400/app
  - 위쪽 빨간 띠: 테스트 서버 · 예시 데이터 · 지금 역할. `/__preview/as/member`(구성원으로 보기), `/__preview/as/owner`, `/__preview/reset`(예시 데이터 처음으로)
  - 바깥 요청(카카오·메일·Supabase 실서버)은 모두 막고, 검색 엔진에서 빠진다(`x-robots-tag`·robots.txt). 127.0.0.1 에만 열린다.
  - 전후 견주기: 같은 예시 데이터로 바꾸기 전 판(V22.9.82 폴더)을 두 번째 창에 띄운다. 이 폴더에서
    `PREVIEW_PORT=4401 PREVIEW_APP_ROOT=../my-v22982-usage-metrics npm run preview:app` → http://127.0.0.1:4401/app
    (PowerShell: `$env:PREVIEW_PORT=4401; $env:PREVIEW_APP_ROOT="..\my-v22982-usage-metrics"; npm run preview:app`). 위 띠에 판 이름이 나온다.
- **휴대폰·다른 사람과 보기(선택, 승인 뒤)**: 별도 Worker `malhaebook-staging`(workers.dev, 비밀번호). `npm run deploy:staging -- --dry-run` 으로 올라갈 모듈·바인딩을 먼저 본다.
  - 바인딩은 판 이름과 비밀번호 Secret 둘뿐, cron·라우트·도메인 없음. 운영 이름(kakao-accountbook)은 도구가 거절한다.
  - Workers Free 의 하루 요청 한도(계정 전체 10만)를 운영과 함께 쓴다. 다 보고 나면 지운다.
  - 올리기는 Cloudflare 토큰이 필요해 사용자가 직접 실행한다(토큰은 가려 입력).

## 4. 디자인 저장소 검토
