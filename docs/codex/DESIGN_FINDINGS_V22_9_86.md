## T-16 실행 취소 — 구현하지 않은 이유

지시서는 "보안 판단이 애매하면 구현하지 말고 보고한다"고 했다. 지금 길로는 수용 기준(남의 거래와 오래된 거래는 지워지지 않는다)을 지킬 수 없어 구현하지 않았다. 성공 알림에는 버튼이 없다(검사가 ‘실행 취소’ 없음을 확인한다).

- **`saved_rid` 는 주소 값이다.** 빠른 입력 저장(`POST /admin/transactions` → handleAdminAddTransaction)은 `/app?msg=added&saved_rid=<기록 id>&saved_qd=…` 로 돌아온다(`admin/transactions-households.js:341–343`). 누구나 이 주소를 만들어 보낼 수 있다.
- **삭제 길은 ‘방금 이 세션이 만든 기록인가’를 보지 않는다.** `POST /my/delete` → handleMyDeleteTransaction(`my/transactions.js:236`)이 보는 것:
  - 로그인 세션, 가계부, 쓰기 권한(canWriteMyHousehold), 기록이 그 가계부 것인지
  - canManageMyRecord(`my/access-control.js:115`): 소유자·관리자는 모든 기록, 구성원은 자기 기록
  - memberRecordChangeError(`my/access-control.js:186`)
  - 만든 사람이 이 세션인지, 만든 지 얼마나 됐는지는 보지 않는다.
- **그래서 `saved_rid` 로 단추를 만들면** 소유자·관리자가 꾸며진 주소(`/app?msg=added&saved_rid=<다른 기록>`)를 열고 ‘실행 취소’를 누르는 것만으로 다른 사람의 기록이나 오래된 기록이 지워진다. 지시서의 "기존 삭제 경로의 검사를 그대로 거친다"만으로는 막을 수 없다.
- **5초만 보이는 조작**은 키보드·화면 읽기 사용자가 닿기 어렵다(WCAG 2.2.1 시간 조절). 알림은 마우스를 올릴 때만 멈춘다.

제안(별도 판, 승인 뒤):
1. 저장 응답이 실행 취소 표를 낸다. 서버 서명(HMAC)에 기록 id·가계부·저장한 사람·만든 시각·만료(약 60초)를 담는다. 서명 키를 새 Secret 으로 두면 Secret 추가 승인이 필요하다.
2. 새 `POST /my/undo` 는 같은 출처, 서명, 만료, 같은 사람, 그 뒤 기록이 바뀌지 않았는지를 확인한다. 그다음 deleteTransactionWithAudit 로 지운다(감사 기록이 남는다).
   - 서명 대신 감사 표(accountbook_transaction_audit)의 ‘만든 사람·시각’으로 확인하는 방법도 있다. 이 경우 웹 빠른 입력 저장이 그 행을 남기는지 운영 DB 에서 먼저 봐야 한다.
3. 표가 없거나 지났거나 권한이 없으면 단추 대신 ‘수정·삭제 화면 열기’ 링크를 둔다.
4. 단추는 10초 이상 보이고, 마우스·초점이 알림 안에 있으면 멈춘다.
5. 검사: 꾸민 표, 지난 표, 다른 사람, 그 뒤 바뀐 기록, 두 번 누름, 다른 가계부.

## 지시서와 다르게 한 것

- **층(z-index)**:
  - 가계부 고르기 시트는 12000 이다. 무지출 축하(11900)보다 아래면 축하 알림이 시트 항목 누름을 가로챘다.

- **T-13**:
  - 칩 동그라미는 CSS 속성 선택자가 아니라 브라우저 categoryKey(V22.9.85 T-09 정본, 서버와 같은 판정)로 키를 정한다. 칩 HTML 바이트는 0 그대로다.

  - ‘자세히’(quickMore) 이름은 그대로다.
  - 예산이 없는 가계부의 금액 전 문장은 서버 문장 그대로다.

  - 게이지는 지시서의 ‘0에서 새 값까지’가 아니라 지금처럼 이전 값에서 새 값까지 620ms 로 채운다. 0에서 다시 채우면 저장할 때마다 게이지가 비었다가 찬다. 어느 쪽으로 할지 사용자가 정한다.
- **T-17** 알약(accent-soft) 면만으로는 탭 바 면과 1.10~1.40:1 이다(네 톤, 라이트 파랑 1.12·다크 파랑 1.16 — 지시서 값). 옛 위쪽 막대(강조색)보다 약하다.

  - 현재 탭은 알약 모양·윤곽선·글자 굵기 800·강조색 글자로 구분된다. 지시서 모양 그대로(윤곽선 없이) 할지는 사용자가 기기에서 보고 정한다.
