# V22.9.139-ADSENSE-MASTER 애드센스 재심사 보강 (2026-11-22)

2026-11-21 Google AdSense 재심사에서 ‘가치가 별로 없는 콘텐츠’ 로 다시 부적격 통보를 받았다. 다른 에이전트가 PR #189 로 보강안을 만들었고, 11-22 에 이 판으로 이어받아 병합 전에 고쳤다(사용자 물음 창 “고치고 세무 계산기 빼기”, 같은 날 everyday-tools PR #87 병합).

## 고친 것 (V22.9.139)

- **A-1** (P2) 공개 푸터가 `tools.malhaebook.com` 으로 이어져 하위 도메인의 양식·계산기 쪽이 본사이트와 함께 보였다. 고침: 공개 푸터의 tools 링크를 뺐고, `live` 모드에서 채워지지 않은 광고 칸(`ins[data-ad-status="unfilled"]`)을 숨긴다. 한국어 tools 의 애드센스 코드는 everyday-tools PR #87 로 껐다.
- **A-2** (P2) 계산표 글 6편의 입력 폼과 결과 표가 색인하지 않는 별도 자산에만 있었다(V107:D-9). 고침: 정본 글 본문 안(`#inline-worksheet`)에 계산표를 넣고, 예산 배분·비상금·카드 전월 실적 글 3편에 미니 계산기를 더했다(계산표 9종). 계산 함수가 바뀌어 계산표 자산 주소 판을 v229139 로 올렸다.
- **A-3** (P2) `/demo` 에서 카카오톡 한 줄 기록이 어떻게 저장되는지 볼 수 없었다. 고침: 봇 해석기(`parseTransaction`)가 화면을 만들 때 읽은 결과를 ‘카카오톡에 이렇게 보내면 이렇게 기록돼요’ 표로 보인다.
- **A-4** (P2) 글 34편의 대표 단추가 모두 같은 `/demo`·`/guides` 였다. 고침: 주제에 맞는 글·계산표로 잇고, `/articles` 맨 위에 계산표 9종 모음을 두고, 계산표 예제와 같은 값을 보여 주는 글 3편에만 차트를 둔다.
- **A-5** (P3) 웹 앱에서 공개 계산표·가이드로 가는 길이 적었다. 고침: `/menu`·`/settlement-summary`·`/reserve-plans`·`/payment-methods`·비로그인 `/my` 하단에 링크를 둔다.

## 이어받으며 병합 전에 고친 것 (운영에 나간 적 없음)

- CI 실패: 분류 표 부재 모드 검사 수가 하한보다 적었다(97,796 < 97,799). 하한을 두 모드 실측 중 작은 값으로 다시 정했다.
- `/demo` ‘실시간 입력 해석기’ 는 페이지 안에 따로 만든 정규식이라 ‘저녁 3만5천원’ 을 30,000원, ‘302호 관리비 230000원’ 을 302원으로 읽고 ‘해석 완료’ 라고 했다. 체험 칸을 빼고 봇 해석기 결과 표로 바꿨다.
- `/about` 의 생성형 도구 밝힘 문장을 지웠던 것을 되살렸다(자동화·생성형 도구 사용을 방문자에게 숨기지 않는다).
- 구조화 데이터에 더했던 `WebApplication`(‘실시간 해석기’ 이름, `isAccessibleForFree` 포함)을 뺐다.
- 세무 계산기 셋(카드 공제 전환·월세·연금저축 IRP)을 뺐다. 카드 공제 계산표에는 공제 대상 자녀 수를 넣는 칸이 없었다(자녀가 있으면 한도가 달라진다). 책임자 검토 없이 세무 범위를 넓히지 않는다(사용자 11-22). 그 세 글의 대표 단추는 글 아래 참고 자료(국세청·법령 원문)로 간다.
- 글 40편에 같은 꼴로 넣었던 차트를 계산표 예제와 같은 값을 보여 주는 3편으로 줄였다. 단위가 섞이거나 근거를 설명할 수 없는 비중, 0원을 길이 16 막대로 그리던 것이 함께 빠진다(0원은 막대를 그리지 않는다).
- 공개 화면 코드의 ‘가상’ 표현이 늘었던 것을 main 과 같은 수로 되돌렸다.
- 계산 함수가 바뀌었는데 1년 캐시 계산표 자산 주소 판을 올리지 않았던 것을 올렸다.
