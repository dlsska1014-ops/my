# V61 수명주기 계약 적용안 검토

이 자료는 검토용 적용안이며 운영 적용 승인이나 실행 결과가 아닙니다. 적용문과 가져오기 중지문은 첫 DO 블록에서 의도적으로 중단합니다. V60의 로컬 전용 SQL을 운영 SQL로 복사해 실행하지 않습니다.

이전 승인으로 저장한 카탈로그의 16개 테이블·116개 컬럼·38개 제약·18개 함수·4개 트리거·ACL·RLS를 다시 연결해 검토했습니다. 모든 관측 테이블의 RLS는 활성화되어 있고 서비스 역할은 BYPASSRLS를 사용합니다. 관측한 일반 역할에는 업무 테이블 쓰기나 업무 RPC 실행 권한이 없습니다. 삭제/INSERT를 수행하는 저장 함수와 현재 Worker의 실제 쓰기 경로는 SAVED_SCHEMA_REVIEW.json에 기록했습니다. 기존 승인 카탈로그 SELECT와 R2 SQL 검증은 재실행하지 않았습니다.

이 카탈로그는 지정 객체만 조회했으므로 전체 운영 스키마를 증명하지 않습니다. 다른 스키마의 참조 FK, 뷰·함수·외부 호출자, 생략된 트리거 함수 본문, schema CREATE·시퀀스 ACL·기본값, 현재 PostgREST 스키마 캐시와 활성 Worker 바인딩을 추가로 대조해야 합니다. 구성원 역할 변경과 거래 수정·삭제가 pending 해시 확인과 경합하는 조건도 운영 검토에 포함합니다. 이 정보가 없으므로 실행 차단문을 제거할 수 있는 최종 운영 SQL이라고 판단하지 않습니다.

적용안은 세 테이블의 배타 잠금을 잡은 한 트랜잭션에서 기존 두 함수의 소유자·권한·search_path와 정규화 본문 MD5를 확인하고, 구형 함수 진입 가드와 직접 쓰기 트리거 및 새 RPC 세 개를 설치합니다. 새 함수는 pg_catalog, pg_temp로 search_path를 고정하고 업무 테이블을 명시적으로 public으로 한정합니다. 새 업무 RPC는 service_role만 실행하며 내부 트리거 함수에는 직접 실행 권한을 주지 않습니다. 구형 RPC의 서비스 역할 직접 실행 권한도 회수합니다. 새 인덱스·테이블·환경변수는 제안하지 않습니다.

운영 전환은 전체 스키마 검토와 구체적인 실행 승인 뒤에 진행합니다. 먼저 가져오기를 거절하는 V61 호환 복구 Worker를 준비하고 활성 content/바인딩을 대조합니다. 진행 중인 요청을 관측하고 SQL 잠금 대기·중단 조건과 장애 창을 확정합니다. 잠금 획득 전에 시작한 거래의 완료를 기다린 뒤 원자적으로 계약을 설치하고 스키마 캐시를 갱신합니다. 모든 인스턴스가 즉시 교체되었다고 가정하지 않으며, 뒤늦은 구형 RPC/REST와 캐시가 낡은 호출은 실패해야 합니다. 새 RPC가 보이지 않는 동안 Worker는 구형 저장 경로로 대체하지 않습니다. 그 뒤 승인된 통합 Worker를 승격하고 실제 /ready, 합성 계정의 가져오기·삭제, CPU/count 비용과 실기기를 확인합니다.

Worker 임대 만료는 DB 요청 취소가 아닙니다. pending의 ID가 존재한다는 사실만으로 완료를 확정하지 않습니다. 원래 전체 저장 필드의 해시를 확인한 뒤 전체 expected 텍스트 CAS로 완료를 저장하고 새 purge를 호출합니다. 원문·유효 토큰이 사라지고 값도 확인되지 않은 pending은 그대로 보존하며 자동 초기화하지 않습니다. 다른 가계부와 소속 불명 구형 해시 상태도 삭제하지 않습니다.

복구는 V61의 같은 실제 소스에서 생성한 가져오기 중지 후보를 사용합니다. 신규 RPC·트리거·상태 계약을 유지하고 V44/V59/V60 준비 Worker로 단순 복귀하지 않습니다. 새 요청을 중지해도 이미 시작한 SQL은 완료될 수 있으므로 저장 상태를 계속 확인합니다. 필요할 때 검토용 20번 파일의 새 commit 권한 회수를 별도 승인으로 실행할 수 있지만, source 확인·조건부 완료·pending 보호 purge는 유지합니다. 해결 후 동일한 새 commit 권한을 복원하는 절차도 별도로 승인받습니다. R2 자산 함수 복구는 이 수명주기 계약과 독립적이며 자동으로 실행하지 않습니다.

현재 허용된 SQL은 127.0.0.1:65460/ab_v60_lifecycle 합성 DB 검증입니다. 운영 SQL·업로드·배포·커밋·푸시는 실행하지 않았습니다.
