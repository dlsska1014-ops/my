2026-10-11에 전달받은 Aside 결과를 정리한 문서입니다. 현재 판정은 **V39 부분 운영 검증 완료**입니다. 이 정리는 새 운영 검사를 실행한 결과가 아니며, 원래 실행 기록의 PASS·FAIL·NOT-RUN·BLOCKED를 바꾸지 않습니다.

## 다음 실행 순서

1. 서비스 버전, 대상 가계부와 보존 자료를 확인합니다. 실제 응답이 `V22.9.39-PUBLIC-GUIDES`가 아니면 V39 검증을 계속하지 않고 남은 항목을 BLOCKED로 기록합니다.
2. 독립 A/B 세션이 준비되면 참여 요청, 승인, 타인 거래의 수정 UI 제한, B의 한 건 기록과 조회 전용 전환을 확인합니다. 역할 변경 전에 받은 정상 거래·카드 목표 폼의 제출도 별도 항목으로 확인하여 UI 제한과 서버 거절을 구분합니다. 준비되지 않은 경우 해당 항목을 NOT-RUN으로 남기고 A만으로 가능한 항목을 진행합니다.
3. 기존 카드의 양수 목표 주간 표시, 실제 IME, 기존 정기 항목의 편집 화면, 복사 거절 시 안내를 각각 분리해서 확인합니다.
4. 실기기와 카카오는 환경이 준비되고 해당 실환경 시험이 요청된 경우에 진행합니다. 앞서 선택한 카카오 코드 검증 방침을 이유 없이 다시 실사용 계정 연결 요청으로 바꾸지 않습니다.
5. 최종 데이터·목표·역할·세션 상태를 재조회하고 새 결과 문서에 남깁니다. 원래 QA 기록은 덮어쓰지 않습니다.

실행 방법, 중단 기준, B의 700원 기록 후 예상 합계와 결과 양식은 [다음 Aside 지시문](ASIDE_V22_9_39_REMAINING_QA.md)에 있습니다. 실제 운영 확인이 끝나기 전에는 미실행 항목을 통과로 표시하지 않습니다.

이번 변경은 QA 기록의 이력 반영과 다음 검증 절차 작성에 한정합니다. Worker 소스, 버전, 고정 릴리스 manifest와 운영 배포는 바꾸지 않습니다. 기존 소스 SHA-256은 `d97e3a60bb881546aacf8953a091152ff16b77cfd5c173452fecb2348cd4a7e5`입니다. SQL·환경변수·Secrets·외부 콘솔 변경이 필요하지 않습니다. 공개 문서에는 합성 테스트 명칭·금액과 판정만 포함하며 비공개 실행 자료와 이미지는 포함하지 않습니다.
