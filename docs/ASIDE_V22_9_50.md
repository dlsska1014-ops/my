# V22.9.50 실기기 확인 안내

이번 작업은 저장소 수정과 로컬 검증입니다. 운영 배포·SQL·환경변수·Secrets·외부 콘솔 변경은 수행하지 않았고 새 SQL이나 외부 설정은 필요하지 않습니다. 운영 적용은 별도 범위입니다.

- iOS Safari·Android Chrome·카카오톡 인앱에서 실제 금액 키보드와 한글 조합·확정을 확인합니다.
- 실제 OS 클립보드의 ₩12,000·8,900원 붙여넣기와 123 가운데 삽입·1,234 가운데 삭제의 커서를 확인합니다.
- VoiceOver·TalkBack에서 다섯 칩의 이름·입력칸 이동·형식 오류·초점 복귀를 확인합니다.
- 실기기의 라이트·다크·금액 가리기·동작 줄이기, 초안 복귀와 자산 실패 후 재시도를 확인합니다.
- 향후 별도 승인으로 운영에 반영하면 점검용 가계부에서 잘못된 금액의 요청 0건·거래 0건, 정상 수정과 예산 초과 지출의 저장값을 확인합니다.

로컬 네이티브 Chrome의 모바일 뷰포트와 통화 문자열 삽입은 위 실기기·클립보드·운영 확인을 대신하지 않습니다.
