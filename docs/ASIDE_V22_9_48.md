# V22.9.48 사용자 확인

이 묶음은 A UI의 선행 입력 수정입니다. SQL·환경변수·외부 콘솔 변경은 필요하지 않습니다. 운영 업로드·승격은 별도 승인과 기존 배포 도구를 따릅니다. 현재 운영 버전은 이번 작업에서 다시 조회하지 않았습니다.

실제 iOS Safari·Android Chrome·카카오 인앱에서 만두·수량 문장, 부수입·상여금·환불·배우자 용돈, 붙여 쓴 날짜와 M-D 날짜를 확인합니다. 일반 시트는 문장 날짜를 적용하고 일별 팝업의 명시 날짜와 직접 고친 날짜는 유지해야 합니다. 없는 날짜는 저장하지 않아야 합니다.

메모만 입력한 기본 분류와 사용자 지정 키워드를 비교하고 실제 저장값을 확인합니다. 추천을 확인하지 못한 경우에는 분류를 직접 입력하거나 저장 후 확인할 수 있어야 합니다. 취소 내역은 구분을 명시하기 전에는 저장되지 않아야 합니다. 실제 보조기기의 안내와 모바일 키보드·커서는 후속 A에서도 확인합니다.
