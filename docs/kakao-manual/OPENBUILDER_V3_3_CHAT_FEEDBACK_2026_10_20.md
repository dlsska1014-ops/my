# OpenBuilder v3.3 지시문 — 2026-10-20 단톡방 피드백 (Worker V22.9.72 와 함께)

Worker 가 바꿀 수 없는 카카오 챗봇 관리자센터(OpenBuilder) 항목을 사람이 바꾸는 순서다. 요구사항 원문과 Worker 반영은 `docs/codex/CHAT_FEEDBACK_REQUIREMENTS_2026_10_20.md`.

전제
- Worker V22.9.72-CHAT-FEEDBACK 을 먼저 운영에 올린다. 아래의 새 버튼 이름(도움말 보기·기록방법·오늘기록…)은 그 판부터 스킬이 읽는다.
- MCP: claude.ai 의 ‘카카오비즈니스 MCP’ 커넥터는 이 세션에서 인증되지 않아 쓰지 못했다. claude.ai 커넥터 설정에서 인증하면 다음 세션에서 같은 절차를 대화로 진행해 볼 수 있다(가능 범위는 커넥터가 주는 도구에 따른다). 인증 전에는 이 문서대로 직접 바꾼다.
- 경로: 카카오비즈니스 → 챗봇 → 말해가계부(그룹 봇) → 시나리오. 저장한 뒤 ‘배포’에서 바꾼 블록만 고른다(부분 배포). 봇 입장 블록에는 2026-10-19 16:09~16:10 의 미배포 편집본이 있으니 A 로 덮어쓴 것을 배포한다.

## A. 봇 입장 블록 (봇이 방에 들어왔을 때 보내는 말)

- 지울 문장: `'@말해가계부'를 안 쓰고 '커피 4,500원'처럼 보내셨네요. 아래 '사용 설명서'를 눌러 모든 기능을 볼 수 있어요.`
- 새 본문(제안):

```
안녕하세요! 함께 쓰는 가계부, 말해가계부예요.
@말해가계부 점심 12000원 처럼 보내면 바로 기록돼요.
아래 버튼으로 시작해 보세요.
```

- 버튼(위에서 아래로):
  1. `웹가계부` — 메시지 버튼, 보내는 문장 `웹가계부` (웹 링크 버튼으로 두려면 https://malhaebook.com/my).
  2. `도움말 보기` — 메시지 버튼, 보내는 문장 `도움말 보기`. 도움말 플러그인은 쓰지 않는다(글만 있는 하단 창이 열린다).
  3. `기록하기` — 챗봇 멘션 플러그인(입력창에 @말해가계부 를 넣는 버튼). 맨 아래.
- 피드백 원문은 `[웹 가계부, 도움말, 기록하기]`. ‘도움말’ 그대로는 기본 도움말 블록(고정 패턴)이 가로채므로 ‘도움말 보기’로 둔다.

## B. 기본 도움말 블록 하단 창 (guide contents, 글만 들어간다)

현재 163자 요약(v3.1)을 아래로 바꾼다.

```
말해가계부 도움말
기록: @말해가계부 점심 12000원
조회: 오늘기록 · 이번달요약 · 남은예산 · 정산
설정: 예산설정 · 이름설정 · 단톡방연결 · 웹가계부
버튼으로 보려면 ‘도움말 보기’를 보내 주세요.
```

## C. 대표 명령어 (현재 13개, ‘도움말’→‘사용 설명서’ 변경본은 미배포)

새 목록(순서대로): `기록방법`, `오늘기록`, `이번달요약`, `남은예산`, `정산`, `예산설정`, `이름설정`, `가계부만들기`, `초대코드참여`, `단톡방연결`, `웹가계부`, `고치기`, `도움말 보기`. ‘사용 설명서’·‘웹 가계부 열기’는 뺀다.
대표 명령어는 시나리오 설정이라 전체 배포로만 반영된다(V22.9.70 기록). 전체 배포 전에 A 의 입장 블록을 저장해 두어야 옛 편집본이 같이 올라가지 않는다.

## D. `01_도움말_전체안내` 블록 (스킬데이터)

패턴 발화에 추가: `도움말 보기`, `기록하기`, `리포트보기`, `예산정하기`, `함께쓰기`, `웹관리하기`, `고치기`, `정기지출`, `기록방법`. 기존 패턴(사용 설명서, 설명서, 기록하는 법, 예산 정하는 법, 리포트 보는 법, 정기지출 설정 방법, 웹 관리 방법, 함께 쓰는 법, 고치는 법)은 남겨 둔다(스킬이 둘 다 읽는다).
`00_시작_메뉴`·`02_기록예시`는 이미 스킬 응답(v3.2)이고, 폴백 블록(스킬)도 그대로다.

## E. 배포와 확인

1. 부분 배포: A(봇 입장), B(도움말 하단 창), D(01 블록). C 는 전체 배포 때 함께.
2. 새 방에 봇을 초대해 확인: 입장 문구와 버튼 3개 → ‘기록하기’를 누르면 입력창에 @말해가계부 → ‘도움말 보기’를 누르면 버튼 5개 카드(리포트보기·예산정하기·함께쓰기·웹관리하기·기록하기) → `도움말` 을 직접 입력하면 하단 창 B 문구.
3. ‘도움말 보기’가 하단 창으로 가면(머신러닝 매칭) 버튼 이름을 ‘전체 도움말’로 바꾸고, Worker 의 `KAKAO_LEGACY_BUTTON_LABELS`(skill-handler.js)에 `"전체 도움말": "도움말"` 한 줄을 추가해 달라고 요청한다.
4. 결과를 `docs/deployments/` 에 OpenBuilder v3.3 기록으로 남긴다.
