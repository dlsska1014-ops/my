# V22.9.56 남은 확인

- E-15 완전 복원, 운영 Cloudflare CPU/요금제, 운영 적용과 실기기/보조기기/실제 BFCache는 확인하지 않았습니다.
- 불명확 저장의 기존 토큰이 만료·소실되고 실제 저장값도 확인되지 않으면 같은 원본의 새 분석을 계속 제한합니다. 새 ID 발급이나 상태 초기화로 복구하지 않습니다.
- 사용한 원본은 같은 연결과 기준으로 다음 묶음을 진행합니다. 연결을 바꾸어 재저장하는 별도 사용자 복구 계약은 제공하지 않습니다.
- 최소 매핑 상태는 기존 설정 보관 계약을 따르며 원문을 저장하지 않습니다. 자동 삭제 작업이나 새 보관 정책은 만들지 않았습니다.
- 모든 제목이 미인식된 표의 명시적 제목 행 선택 UI는 제공하지 않습니다. 실제 제목을 명확히 지정한 표로 다시 입력하는 복구 안내를 제공합니다.
- C 비교·관리자 감사·환급 정산 실제 반영·정기 실행·Git/운영 게시는 별도입니다.
