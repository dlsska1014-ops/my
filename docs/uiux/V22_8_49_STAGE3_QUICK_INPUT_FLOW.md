# V22.8.49 빠른 입력 흐름

## PC

`빠른 입력` 버튼 → 중앙 모달 → 기존 `section#add` 입력폼 → 기존 거래 POST 저장 경로

## 모바일

하단 중앙 `입력` → 바텀시트 → 기존 `section#add` 입력폼 → 기존 거래 POST 저장 경로

## 날짜 연동

좌측 또는 홈 캘린더 날짜 → 일별 상세 → `이 날 기록 추가` → 해당 날짜가 선택된 빠른 입력

## 안전 원칙

- 입력폼을 복제하지 않는다.
- 별도 거래 쓰기 API를 만들지 않는다.
- 현재 선택 가계부, 서버 권한, 중복 방지, 분류·결제수단 처리 계약을 유지한다.
- JavaScript를 사용할 수 없으면 기존 `/app#add` 링크가 점진적 대체 경로가 된다.
