# V22.8.48 일별 상세 팝업 흐름

1. 사용자가 좌측 미니 캘린더 또는 홈 캘린더의 날짜를 누른다.
2. 기존 링크 이동을 잠시 중단하고 로딩 모달을 연다.
3. `/u/api/day-transactions`가 로그인 세션과 참여 가계부 범위를 확인한다.
4. 선택 날짜의 거래만 읽어 지출·수입 합계와 항목을 반환한다.
5. PC에서는 중앙 모달, 모바일에서는 하단 바텀시트로 표시한다.
6. `전체 기록에서 보기`를 누르면 기존 날짜 필터 페이지로 이동한다.
7. JS 또는 API 오류 시 원래 날짜 링크가 안전한 대체 경로로 남는다.

다음 3단계에서는 빈 날짜와 전역 빠른입력 버튼을 기존 거래 저장 흐름에 연결한다.
