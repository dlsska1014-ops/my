# V22.8.50 빠른 실행·저장 복귀 흐름

## PC 빠른 실행 독

`거래 검색 · 빠른 입력 · 알림 · 화면 설정`을 본문 하단 중앙에 고정합니다. 사이드바가 펼쳐지거나 접혀도 남은 본문 영역의 중앙을 기준으로 배치합니다.

## 저장 성공

1. 빠른 입력에서 선택 날짜를 `return_to`에 동기화
2. 기존 `/admin/transactions` POST 저장
3. `msg=added&day_detail=1`로 선택 날짜 캘린더에 복귀
4. 성공 피드백 카드 표시
5. 해당 날짜 일별 상세 팝업 자동 열기
6. 일회성 URL 상태 제거

## 저장 오류

1. 서버 검증 또는 권한 오류 발생
2. `err=...&quick=1`로 같은 날짜에 복귀
3. 오류 피드백 카드 표시
4. 기존 입력 팝업 자동 열기
5. 사용자가 날짜를 다시 찾지 않고 입력값을 보정

## 안전 원칙

- 입력폼이나 거래 쓰기 API를 추가하지 않습니다.
- 현재 가계부 범위, 서버 권한, 분류·결제수단, 중복 방지 계약을 유지합니다.
- 성공과 실패를 URL의 일회성 상태로 구분하며 클라이언트가 표시 후 정리합니다.
- JavaScript가 실행되지 않아도 기존 서버 리다이렉트와 `/app` 입력 섹션을 사용할 수 있습니다.
