# V22.9.43 운영 적용 안내

단톡방 자동 참여(승인 단계 없음)와 구성원 권한이 바뀝니다. 운영 V22.9.42(빈 멘션 응답)와 미배포 V22.9.41(관리자 로그인 복귀)이 함께 들어갑니다. SQL·변수·Secrets·관제 Worker 변경은 없습니다.

1. **하네스 확인.** `node .codex/scripts/verify-repository.mjs`, `npm run validate:categories-absent`, `node monitoring/test-d1.mjs`가 통과하는지 봅니다.
2. **앱 Worker.** `node tools/deploy-worker-version.mjs`로 업로드하고 바인딩·런타임·소스·내보내기를 대조합니다. 승격(`--promote <버전 ID>`)은 별도 승인 뒤에 합니다.
3. **배포 뒤 확인.**
   - `/health`의 판 `V22.9.43-ROOM-AUTOJOIN`.
   - V22.9.41: `curl.exe -sI https://malhaebook.com/ops-monitor` → 303, `location: /admin-view?return_to=%2Fops-monitor`.
   - V22.9.42: 단톡방에서 봇만 멘션한 빈 발화에 짧은 안내와 도움말·챗봇 멘션하기 버튼이 나옵니다.
   - 테스트 단톡방(운영 DB에 가계부·참여·거래 행이 생깁니다):
     - 새 팀채팅에서 A가 ‘커피 4500’을 보내면 "웹 로그인 없이 이 방의 공동 가계부를 준비했어요"와 ‘참여자 권한: 기록·수정’이 나옵니다. V22.9.42까지는 이 자리에서 "이 단톡방에 연결된 가계부가 없습니다"가 나왔습니다.
     - B가 ‘우유 3300’을 보내면 ‘이 방의 공동 가계부에 참여했어요 … 내 권한: 기록·수정’이 나옵니다.
     - A가 ‘구성원 권한 기록만’을 보내면 B의 ‘삭제 01번’이 ‘기록만’ 안내로 거절되고, B의 새 기록은 저장되며 저장 안내에 수정·삭제 문구가 없습니다.
     - A가 ‘구성원 권한 기록 수정’으로 되돌립니다.
   - 웹 참여자·초대 화면(소유자)에서 ‘구성원 권한’ 칸을 저장해 봅니다.
   - 확인이 끝나면 테스트 가계부를 웹에서 삭제합니다.
4. **선택(OpenBuilder).** 도움말 블록(v2.4)에 단톡방 참여를 "초대코드로 참여·승인"으로 설명한 문장이 있으면 "이 방에서 거래를 보내면 승인 없이 참여하고, 소유자는 ‘구성원 권한’으로 기록만/기록·수정을 정한다"로 바꿉니다. 코드 동작에는 필요하지 않습니다.
5. **되돌리기(앱 Worker).** 문제가 있으면 승인 후 `node tools/deploy-worker-version.mjs --rollback a371e559-163f-43e0-bae8-b82c00c6c08c`로 V22.9.42(배포 `b9bf820c-5275-4625-90a1-8c765a12c7b9`, 소스 SHA-256 `71140ad0f4c2791e0a7efd4d064ad64b26b42fe82c37c70265c14d66993fc8ef`)로 돌아갑니다. 자동 참여로 생긴 구성원 행과 권한 줄은 남으며, V22.9.42는 권한 줄을 읽지 않으므로 모든 구성원이 기록·수정으로 동작합니다.
