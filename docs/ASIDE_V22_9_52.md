# V22.9.52 남은 수동 확인

로컬 구현·자동 검증은 운영 적용이나 실기기 검증을 뜻하지 않습니다. 아래 환경은 실제로 확인했을 때만 통과로 기록합니다. 기존 V51의 미확인 항목도 유지합니다.

- iOS Safari·Android Chrome·카카오톡 인앱에서 두 예산 폼의 실제 숫자 키보드·한글 조합·선택 치환·중간 삽입·줄 추가 및 제거를 확인합니다. 1.5·-10·1e3·잘못된 쉼표가 원문과 오류로 유지되어야 합니다.
- 실제 OS 클립보드로 정상 쉼표·원·단위 표현과 잘못된 금액을 붙여넣고 정정 후 저장을 확인합니다. Chrome CDP Input.insertText는 OS 클립보드 확인을 대신하지 않습니다.
- VoiceOver·TalkBack에서 세 합계는 입력마다 반복 발화하지 않고, 입력을 멈춘 뒤 전용 상태 영역에서 묶어 안내하는지 확인합니다. 행 오류·제외 안내·기본 수입 이름·음수 차액·원래 지문을 보존하는 충돌 안내도 확인합니다.
- 실제 창 확대·라이트/다크·네 톤·금액 가리기·모션 줄이기에서 긴 이름과 큰 합계가 잘리지 않고 초점이 보이는지 확인합니다.
- 미저장 입력을 유지한 채 다른 월·가계부와 문서로 이동한 뒤 실제 뒤로 가기를 수행합니다. pageshow.persisted와 미복원 사유를 함께 기록합니다. persisted=true인 실제 BFCache cache-hit는 아직 확인하지 않았습니다. no-store를 제거하여 검사를 통과시키지 않습니다.
- 승인된 적용 단계에서만 운영의 실제 로그인·관리 권한·카카오 예산 안내·동시 관리자 충돌을 확인합니다. 이번 로컬 작업에서는 운영과 외부 설정을 변경하지 않았습니다.

숨은 __total·__income 행은 편집 합계에 더하지 않습니다. 저장하면 현재 입력한 일반 행만으로 전체 월 계획을 교체한다는 안내를 확인한 뒤 사용합니다. 결과 불명확에서는 먼저 최신 저장 계획을 확인하고 입력과 비교해야 합니다.
